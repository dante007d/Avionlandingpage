# AVION — Tech Events 2026

> **Advancement · Vision · Innovation · Opportunity · Next Generation**  
> Three challenges, one arena. Think beyond the signal.

A futuristic, high-performance landing experience designed with 3D ASCII canvas art, scrolling dual-instance LED matrix displays, interactive card video loops, bidirectional scroll reactions, and mobile/Android-optimized modal briefings.

---

## ⚡ Features

- **3D ASCII Torus Knot**: Real-time rotating (2,3) trefoil knot rendered as lit, z-buffered ASCII art directly on HTML5 Canvas.
- **Amber & Crimson LED Matrix Displays**: Dual 5×7 chunky pixel font marquee running on the top navbar and hero Challenge Radar card.
- **Futuristic Typography**: Styled with Google Fonts `Orbitron` display font, metallic gradient chrome reflections, and symmetrical laser HUD wings.
- **Interactive Stacking Challenge Cards**:
  - **Case 01 — Project Eclipse**: AI threat investigation & forensics.
  - **Case 02 — Cyber Mystery Arena**: Digital forensics & mystery puzzle decoding.
  - **Case 03 — Topic Auction Challenge**: Strategic auction and competitive topic conquest.
- **Performance Optimized**: Viewport-aware Intersection Observer pauses off-screen videos to eliminate lag on Android and mobile hardware.
- **Cyber Glitch Signal Section**: Chromatic RGB aberration slicing with scanlines and quantum telemetry specs.
- **Infinite Events Marquee**: Continuous looping ticker of active event operations with one-click briefing sheets.
- **Pure Text Information Sheet**: Clean, accessible bottom-sheet modal with swipe-to-dismiss gesture on mobile.

## 🚀 Quick Start

Serve with any local static HTTP server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
